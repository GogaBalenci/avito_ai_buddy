# Документы проекта (SDD)

Спецификации написаны до кода. Требования из `09`–`11` разложены в OpenSpec: действующие — `../openspec/specs/<capability>/spec.md`, история изменений (proposal, design, tasks, дельты) — `../openspec/changes/archive/`.

## Порядок чтения
1. `12-architecture.md` — структура репозитория, компоненты, OpenAPI, контракты MCP, схема БД и Redis, тесты, CI.
2. `13-permissions.md` — права RBAC + ABAC: роли, условия, матрицы «роль × инструмент / эндпоинт / документ», тесты отказов.
3. `09-spec-agent.md` — агент «Авиитик Витя»: вход чата, намерения, режим `demo`, промпты, подтверждение, эскалация, запреты, события.
4. `10-spec-s3-time-off.md` — S3 «Оформление отгула» (основной сценарий вместе с S1).
5. `11-spec-s1-s2-s4.md` — S1 «Мой путь», S2 «Вопросы о команде и инструментах», S4 «Запросы доступов и в каналы».

## Контекст и история
- `08-intern-journey.md` — путь стажёра (CJM) по чек-листу Авито и формат YAML-треков, синтетический Frontend-трек.
- `16-qa-webinar.md` — выжимка Q&A с экспертом кейса (10.11.2026): уточнения требований.
- `17-qa-patch.md` — патч к `09`–`11` после Q&A и архитектуры; перенесён, оставлен как история правок.
- `source/` — исходный чек-лист стажёра Авито из кейса (CSV): `checklist-common.csv` («Материалы для всех»), `checklist-backend.csv` («Чек-лист Backend»). Из них собираются `content/tracks/common.yaml` и `backend.yaml`.

Все инструкции, порядки и матрицы в этих документах — тестовые допущения команды, а не регламенты Авито.
