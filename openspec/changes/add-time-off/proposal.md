# Change: add-time-off — S3 «Оформление отгула»

## Why
Пример из кейса и единственное действие через корпоративный сервис в основном сценарии допуска (S1 + S3): результат должен вернуться, отобразиться и сохраниться. Стажёр оформляет отгул за минуту без похода к наставнику, а наставник видит предстоящие отгулы своих стажёров.

## What Changes
- Намерение `time_off` (текст, кнопка `intent:time_off`), тестовый порядок со ссылкой, форма «от — до» без поля «причина».
- Правила дат (8 кодов) одним пакетом Go для API и `mcp-mocks` и Zod на фронте, общие тест-векторы.
- Черновик с явным подтверждением, идемпотентный `confirm`, MCP-инструменты `absences.create_request` и `absences.list_requests`.
- Отображение в «Моих заявках», истории и у наставника; имитация сбоя сервиса в демо-панели.

## Impact
- Affected specs: time-off (новая).
- Affected code: `internal/timeoff/rules`, `internal/actions`, `internal/mcpmocks/absences`, `contracts/absences/*`, `contracts/common/*`, `web/src/features/time-off`.
- Вне скоупа: отмена заявки, баланс, отпуск и больничный, производственный календарь, согласование руководителем.
- Источник: `docs/10-spec-s3-time-off.md` v1.3.
