## ADDED Requirements

### Requirement: AG-07 Ответ с источником или честное «не нашёл»
Каждый ответ с фактами о процессах, инструментах или порядке действий SHALL содержать ссылку на источник из базы знаний; без источника — честное «не нашёл» и предложение спросить наставника.

#### Scenario: Не нашёл (T-18)
- **WHEN** стажёр пишет «как устроен квантовый компьютер»
- **THEN** sources пуст, текст «ответа не нашёл, а придумывать не буду», событие escalated{reason: no_answer}

### Requirement: AG-08 Плашка тестовой инструкции из label
Ответ по документу базы знаний SHALL показываться с плашкой «тестовая инструкция» или «тестовое описание»; плашку рисует UI по полю `sources[].label`, а не текст модели.

#### Scenario: Тестовая инструкция (§14.1-9)
- **WHEN** получен любой ответ kb_question
- **THEN** у каждого источника label не пуст и UI показывает плашку

### Requirement: AG-09 Термин без источника — только тестовое описание
Термин с `source_level: none` SHALL объясняться только тестовым описанием с фразами «тестовое описание» и «уточни у наставника».

#### Scenario: stash (§14.1-8)
- **WHEN** стажёр пишет «что такое stash?»
- **THEN** ответ содержит «тестовое описание» и «уточни у наставника», источник с label=test_description

### Requirement: AG-10 Тестовые инструкции не выдаются за регламенты
Агент SHALL NOT выдавать тестовые инструкции за регламенты Авито: переформулировка с запрещёнными оборотами (§7.3, правило 6) отклоняется, используется шаблон.

#### Scenario: Запрещённый оборот (§14.1-10)
- **GIVEN** модель переформулировала ответ словами «регламент Авито»
- **WHEN** ответ проверен ReplyGuard
- **THEN** отдан текст шаблона, событие llm_rephrase_rejected

### Requirement: AG-11 Переформулировка сохраняет обязательные значения
Переформулированный текст SHALL сохранять все обязательные значения черновика (номера заявок, даты, маркеры источников, обязательные фразы) и SHALL NOT добавлять новые числа и даты; иначе — шаблон.

#### Scenario: Новая дата (§14.1-10)
- **GIVEN** модель добавила в ответ дату, которой нет в черновике
- **WHEN** ответ проверен ReplyGuard
- **THEN** отдан текст шаблона, событие llm_rephrase_rejected{rule}

### Requirement: AG-19 Серверные состояния маскота
Каждый ответ SHALL содержать `mascot_state` из четырёх серверных значений (`thinking` ставит только клиент, §10).

#### Scenario: Состояние в каждом ответе (§10.2)
- **WHEN** сервер отдаёт любой AgentReply
- **THEN** mascot_state ∈ {hello, done, oops, ask_mentor}; thinking сервер не возвращает

### Requirement: AG-26 Текст без исполнения HTML
Текст ответа, заголовки и тела документов SHALL отображаться без исполнения HTML/скриптов: `text` — только как текст с разбором маркеров `[n]`, markdown документов — через санитайзер.

#### Scenario: XSS (§14.1-18)
- **GIVEN** документ базы знаний или ответ модели содержит <img src=x onerror=alert(1)>
- **WHEN** ответ отображён
- **THEN** скрипт не выполняется, текст показан как текст
