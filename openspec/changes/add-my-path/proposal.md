# Change: add-my-path — S1 «Мой путь адаптации»

## Why
Первая половина основного сценария допуска и прямое требование критериев: с первого экрана стажёру понятно, на каком он этапе, какие шаги закрыты и какой один шаг сделать дальше. Чек-лист Авито перемешан по ролям и периодам; бадди показывает только шаги стажёра в рекомендуемом порядке и снимает с наставника вопрос «что мне делать дальше?».

## What Changes
- Этап по дню от старта (`week1` … `after3`), видимые шаги `owner: intern`, порядок с разрешением ничьих.
- Статусы шагов по таблице переходов (`internal/checklist/fsm`); шаг с заявкой закрывает только бадди.
- Один следующий шаг: хвосты прошлых этапов → текущий → ближайший будущий; плашка «Ждём ответа».
- «Отметить пройденным» / «Вернуть в работу» идемпотентно с `expected_status`; основная кнопка шага — payload `step:`.
- Треки — YAML-данные с проверкой загрузчиком (новый трек без кода); экран наставника «Мои стажёры» только для чтения.

## Impact
- Affected specs: my-path (новая).
- Affected code: `internal/path`, `internal/tracks`, `internal/checklist/fsm`, `internal/mcpmocks/checklist`, `content/tracks/*`, `contracts/checklist/*`, `web/src/features/path`, `web/src/features/mentor`.
- Источник: `docs/11-spec-s1-s2-s4.md` v1.2, раздел 1.
